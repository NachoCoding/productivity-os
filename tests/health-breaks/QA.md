Site selection applies to a new plan; updated durations apply to the next round. Posture coaching remains off and no camera permission is requested. Actual posture calibration and real sleep/lock behavior require the separate manual acceptance procedure in `tests/posture/QA.md` (when present); virtual lifecycle coverage does not claim those physical checks.

## Reliability pass (2026-10-08)

- **Self-healing:** a focus paused as `away` or `monitor` while Health Breaks is present (an unlock racing the root probe, or a briefly unavailable probe) retries its checkpoint after 2 s, then every 10 s three times, then every 30 s, without a manual Resume. Helper errors use the same schedule. Every 5 s the reminder tick clears `lock`/`session` reasons that `CGSessionCopyCurrentDictionary` no longer reports and `display`/`sleep` reasons once the main display is awake; a reason must be at least 10 s old, and the tick never adds one. Health Breaks holds a `userInitiatedAllowingIdleSystemSleep` activity only while focus runs or recovers, so App Nap cannot stretch checkpoints past the helper's 15 s lease; idle sleep stays allowed.
- **Countdown:** the display estimate runs up to 15 s past the last helper reply (the helper's own credit limit), so it no longer freezes at 10 s and jumps. 1 Hz ticks fire 20 ms after each displayed second changes and re-align after every reply; the menu-bar title is redrawn only when its text changes.
- **Menu and CPU:** the status menu is built once and relabelled in place when it opens; an open menu shows live Pomodoro progress. The 5 s tick no longer rebuilds it. Posture eligibility updates only on input changes (tick, suspend, pause, launch, opening Posture Coach), and posture status changes only relabel the menu, which removes the per-second posture work and the status-change re-entrancy.
- **Silent start:** `pos-health://pomodoro-start` (and the menu's Start Pomodoro / Start Next Focus) opens no window: no plan starts one, a ready plan starts the next focus, and a running round only reports its status. A 3-second confirmation panel that cannot become key shows the result ("Focus started · 25:00", blocked groups). Errors open the Pomodoro controls with the message. `pos-health://pomodoro-settings` opens Pomodoro Settings; `pos-health://pomodoro` still opens the controls.
- **Stalled rounds (blocker v4):** `stalled: true` shows "· Stalled", and the controls and status menu point to Raycast → Blocked Sites → "End Stalled Round…" (site blocks stay). Blocker v3 replies without the field still decode.
- **Start at login:** the toggle writes the shared LaunchAgent contract atomically (`KeepAlive` `{SuccessfulExit = false}`, `ProcessType` Interactive, `ThrottleInterval` 30, plus the existing keys); turning it off only deletes the file. Quit and duplicate-instance exits remain status 0, so launchd restarts only crashes.
