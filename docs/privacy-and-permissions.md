# Permissions and local data

[Documentation index](README.md)

Permissions depend on the feature you enable. Source builds use local signing; this repository does not distribute signing keys or a notarized installer.

## Permissions

| Feature | Access and why |
| --- | --- |
| Website blocking | Administrator setup installs a root-owned helper, scoped sudoers rule, and expiry service; the helper modifies its marked hosts section |
| CPU Priority | Separate administrator setup; adjusts nice values for identified coding processes |
| Screenshot Studio | Screen Recording for capture; Accessibility for automatic scrolling; microphone only when recording with microphone audio |
| Clipboard History | Reads plain-text clipboard contents while collection runs; Accessibility for automatic paste |
| Posture Coach | Camera only after you enable and calibrate; requires the built-in MacBook camera |
| Health Breaks | Observes idle/session state; ordinary reminders do not record keystrokes or use the camera |
| Keep awake | Raycast automation permission to control the separately installed Amphetamine app |
| Resource Guard | User-level process/resource observations; installer also adds marked agent instruction sections |

Use System Settings → Privacy & Security to inspect or revoke system permissions. Revoking one permission can disable that feature while other tools continue to work.

## Stored data

| Component | Stored data and retention |
| --- | --- |
| Clipboard History | `~/Library/Application Support/Productivity OS/Clipboard History/history.sqlite`; text/source labels encrypted with AES-GCM and a login Keychain key. Ordinary entries expire after seven days from last copy; favorites persist until deleted |
| Drop Shelf | `~/Library/Application Support/Productivity OS/Drop Shelf`; local shelf metadata and saved images, not encrypted by the app |
| Screenshot Studio | User-selected exports and editable `.posshot` projects; temporary sessions under `~/Library/Application Support/Productivity OS/Screenshot Studio/Sessions`, with crash recovery and 24-hour expiry |
| Health Breaks / Posture Coach | Local preferences and calibration numbers; camera frames are processed locally, not saved or uploaded; ordinary active-time counters reset with the helper |
| Resource Guard | `~/Library/Application Support/Productivity OS/Resource Guard`; job identities, executable names, directories, timestamps, and diagnostic state; no command arguments, environment values, or command output |
| Website blocker | Marked `/etc/hosts` entries and root-owned state under `/Library/PrivilegedHelperTools/productivity-os` |

Clipboard collection skips marked confidential/temporary/autogenerated entries and excluded apps. It cannot reliably recognize every unmarked secret. Excluding an app affects future collection; clear prior entries separately. Other clipboard managers maintain independent history.

Drop Shelf can download image content when you explicitly import a remote image. Native Share actions send selected content through the chosen destination. These operations differ from local storage. Inspect a shelf before sharing it.

Blur and pixelation are visual effects, not guaranteed redaction. Editable screenshot projects retain originals. Share flattened exports and review the result when concealing private content.

## What uninstall retains

Native uninstallers preserve user data/preferences. Clipboard uninstall preserves the encrypted database and its Keychain key. Resource Guard removal preserves diagnostic state and instruction backups. Use feature-specific clear-history actions before uninstall if you want their contents deleted. See [Uninstall](uninstall.md).

## Reporting a bug

Share only the command, macOS version, error text, and reproduction steps needed. Remove clipboard contents, captured screens, local paths, tokens, and personal data from diagnostics before posting publicly.
