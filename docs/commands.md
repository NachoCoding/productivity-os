# Command reference

[Documentation index](README.md)

Names match `package.json`. Open them through Raycast; the dashboard also links to major tools.

| Command | Purpose |
| --- | --- |
| Productivity OS | All your tools in one place: screenshots, clipboard, Drop Shelf, health reminders, RAM, CPU priority, keep awake, and website blocking |
| Start Pomodoro | Start the next protected focus round with your saved durations and websites, without opening a window |
| Pomodoro | Open the Pomodoro timer: focus rounds, breaks, and the websites each round protects |
| Posture Coach | Optional local posture reminders while you work, independent of Pomodoro; off until enabled and calibrated |
| Review Unblock Request | Review unblocking sites after a one-minute pause; opened directly, it lists the blocked sites to choose from |
| Health Break Settings | Set up eye, stretch, and water reminders and the optional local posture coach |
| Take a Health Break | Show a gentle eye, stretch, and water break popup now |
| New Drop Shelf | Collect files, text, links, and images in a translucent floating shelf |
| Add Clipboard to Shelf | Create a floating shelf with the current clipboard |
| Drop Shelf Settings | Configure shake activation, shortcut, and login startup |
| Clipboard History | Search and paste your local text and code clipboard history |
| Clipboard History Settings | Configure collection, privacy, shortcut, and login startup |
| Resource Guard | Free RAM for Warp and agents by choosing other apps to quit; prioritize coding processes and coordinate heavy jobs |
| Record Short Clip | Record up to two minutes of the screen, with optional audio, trimming, and GIF export |
| Copy Text from Screen | Select an area and copy its text, recognized locally on this Mac |
| Scrolling Screenshot | Capture a scrolling area vertically or horizontally, automatically or as you scroll |
| Capture Window | Click a window to capture it, then annotate, copy, save, or pin it |
| Capture Area | Drag over part of the screen to capture it; Space switches to window selection |
| Capture Screenshot | Open the capture overlay to choose an area, window, display, text, or recording |
| Screenshot Studio | Every capture, annotation, OCR, scrolling, and recording tool in one searchable list |
| Block Site | Block a website by domain |
| Unblock Site | Review and unblock a website after a one-minute pause; unfinished focus rounds stay protected |
| Blocked Sites | List blocked websites; unblock one, a tag, or everything |
| Block Preset | Block or unblock a whole preset of websites (Social, News, Video) |
| Start Focus Session | Block a preset for a set duration, then auto-unblock |
| Quick Focus | Start a focus session right from the search bar: pick what to block and for how many minutes (default: Social for 30) |
| Menu Bar Focus Timer | Menu bar lock icon and countdown for focus sessions and Pomodoro rounds, with quick website, screen, and tool controls |
| Toggle Color Filters | Turn the macOS Color Filters accessibility setting (e.g. Grayscale) on or off |
| Toggle Menu Bar Icons | Hide or show the menu bar icons to the left of the Productivity OS divider |
| Lock Screen and Keep Awake | Lock the screen while the Mac keeps running: starts a keep-awake session that lets the display sleep (empty: no time limit; replaces a running session), then locks |
| Start Keep Awake | Keep the Mac awake for Amphetamine's default session length; leaves a running session alone |
| Quick Keep Awake | Keep the Mac awake for the hours, minutes and seconds typed inline (all empty: no time limit); replaces a running session |
| End Keep Awake | End the current keep-awake session |
| Keep Awake Time Remaining | Show the time remaining in the current keep-awake session |
| Configure Keep Awake | Keep the Mac awake for a duration (empty: no time limit) or until a specific time; replaces a running session |
| Run Setup | Verify the helper installation and show the setup command |

## Default shortcuts

| Shortcut | Action |
| --- | --- |
| ⌘⇧2 | Screenshot area selection |
| ⌘⇧V | Browse/paste Clipboard History |

Other shortcuts can be configured in the relevant helper settings or Raycast. Clipboard cycling, modifier-release paste, and all feature limits are covered in the [user guide](user-guide.md).
